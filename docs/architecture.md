# 架构与协作不变量

## 一个数据库入口

```text
浏览器 React UI ───────────┐
CLI ──────────────────────┼── HTTP /api ── Node.js 24 daemon ── 本地 SQLite
Agent ── stdio MCP 代理 ───┘
```

- daemon 是运行时唯一数据库入口；客户端不各自打开数据库
- UI、CLI、MCP 共用业务命令，避免三套不同的状态规则
- MCP 是真正的 stdio server：实现协议握手、工具发现和调用，再将操作转为本机 HTTP 请求
- 服务不管理 Agent 进程，不运行 shell，不创建 Git worktree，不执行证据引用
- 数据保存在用户目录，构建产物在 `dist/`，二者互不混用

## 数据概念

| 对象          | 作用                                                 |
| ------------- | ---------------------------------------------------- |
| Project       | 项目名称、说明和仓库引用                             |
| Task          | 工作目标、验收标准、优先级、父任务、依赖、状态与版本 |
| Attempt       | 一次领取形成的执行尝试，包含 Agent 标识、心跳和租约  |
| Handoff       | 某次 attempt 提交的摘要、证据和后续事项及人工决定    |
| Comment       | 任务中的协作记录                                     |
| SessionRef    | 外部 Agent 会话的引用；不会自动打开或接管会话        |
| ActivityEvent | 板内操作历史，供追踪变更；不是防篡改审计日志         |

任务 ID、attempt ID 和交接 ID 由服务生成；调用者应当把它们当作不透明字符串。时间使用服务端时间与 ISO 字符串。`Actor` 的姓名、类型、provider 与 sessionId 是声明的信息，不能当成经过认证的身份。

## 状态机

```text
ready ──领取──> running ──交接──> review ──人工接受──> done
  ↑                │               │
  │                │               └──人工退回──> ready
  │                └──人工回收───────────────> ready
  │
  └──人工解除阻塞── blocked
```

任务也可被标记为 `blocked` 或由人取消为 `cancelled`。取消、阻塞、回收、退回都会按命令语义结束当前执行所有权；不能把状态当普通字符串任意写入。详见 [命令表](api.md)。

`parentId` 表示结构关系；`dependencies` 表示开工前置条件。父子层级与依赖是不同关系，不应把“是子任务”理解成“已自动建立依赖”。父子任务是否完成也不替代人工验收。

## 并发与版本

1. **原子领取**：同一个可领取任务的并发 claim 只能有一个成功，其他调用者读取最新状态后另选任务
2. **乐观并发**：带版本的写操作提交 `expectedVersion`；版本冲突时刷新，重新判断，不盲目重放旧输入
3. **依赖门槛**：领取前所有依赖都必须为 `done`；依赖引用和环在服务端验证
4. **执行代次隔离**：token 绑定领取产生的 attempt。回收后产生的新 attempt 不接受旧 token
5. **租约有效期**：超时 token 不能靠迟到的心跳自行复活
6. **人工验收**：Agent 只能提交到 `review`。MCP 不暴露接受、退回、回收等人工控制工具

“人工”规则约束正常客户端流程，而不是账户隔离：所有可访问本机 API 的进程都在信任域内，能够自行构造 actor。若需要阻止恶意 Agent 冒充用户，必须先设计独立认证与授权层。

## 租约与失联

租约默认 300 秒，最短 30 秒，最长 3600 秒。Agent 必须主动发送心跳，不会因为 MCP 连接还存在就自动续租。

当 `leaseUntil` 已经过期，UI 可显示失联，但任务状态仍保留 `running`。daemon 不自动重排任务，也不推断原执行已经停止。人应先确认旧 Agent 是否仍在写文件，再人工回收；否则可能产生仓库层面的并行写入。

重启 daemon 不会启动或恢复 Agent 进程。未到期租约仍按持久化时间判断；已经过期的租约仍需人处理。

## 边界与后续方向

v0.1 的可信边界是一台机器上的可信本地进程。`127.0.0.1` 绑定、Host/Origin 检查和非通配 CORS 限制来自网页的意外访问，但都不能认证本地调用者。

局域网协作需先增加明确的身份、权限、TLS、令牌管理和安全迁移设计。不得通过反向代理、隧道或修改监听地址把当前版本直接当成多人服务。

备份、恢复和威胁模型分别见 [运维说明](operations.md) 与 [安全说明](../SECURITY.md)。
